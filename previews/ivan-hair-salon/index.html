Quick before/after audit

The existing site has the right information, but the presentation and booking path feel dated. This concept reframes the same business as professional, convenient, and appointment-ready.

Current: email bookingThe “Book an Appointment” CTA opens email, which adds friction and can lose customers after-hours.
Current: dated mobile feelMissing mobile viewport and dense service tables make the phone experience harder than it should be.
Current: weak trust signals“Testimonials AI” reads like placeholder copy. Real Google reviews and gallery content would build trust faster.
OpportunityModern mobile website + online booking + clearer service menu = easier conversions for downtown walk-in/search traffic.
