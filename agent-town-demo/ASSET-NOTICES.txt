# Asset provenance and notices

The town is original pixel raster artwork drawn by src/art.js and src/architecture.js using Canvas2D integer rectangles. Architecture selectively reuses the accepted local 2D silhouettes, with deliberately chosen limestone, charcoal and porcelain material values, quieter surfaces and new stone avenues, engraved plaza, clipped trees and silver canal. This is authored neutral raster drawing, not a CSS grayscale filter. No external town tiles, game art, fonts, textures or 3D models are shipped. Inspired by the supplied plaza composition: open square, workshops, trees, bulletin and central guide. All lighting is illustrative, not telemetry. The original town reference is preserved only under references/ and is not shipped.

Adeel's smiling portrait and sprite heads are crops of the user-supplied character sheet, neutralized at export. The 48 × 72 walking sprites combine those reference head crops with an original authored raster body: opposing arms, articulated thighs/knees/shins, raised passing foot and stable supporting-foot baseline. Four directions each have one idle and four distinct walk poses; left uses a reflected side head/body with independently exported phases. These are NOT AI-generated images, and are NOT shifted whole-body crops. tools/crop-assets.js, src/sprites.js and tools/make-sprites.js reproduce them; evidence/crops.json and evidence/sprite-provenance.json record provenance/hashes. Official standalone Codex image generation was blocked by CHATGPT_LOGIN_REQUIRED; no token copying, auth changes or paid fallback was used. Original sheet remains only in references/. User-supplied artwork ownership is not inferred or relicensed; independent review must confirm publication rights and likeness adequacy.

Public stable identity metadata and the data.js validator/store, adapter.js dormant transport, demo.js synthetic fixture are selectively reused from the accepted local Agent Town client 0.1.0. AK project source, no public source license inferred. adapter.js is source-only and is not shipped in either static build. No backend is rebuilt, changed or deployed.

Runtime dependencies: none. Native browser Canvas2D, HTML/CSS and system Georgia/Arial/monospace font fallbacks. No external font network requests. System ffmpeg encodes actual Chromium compositor captures for QA evidence only; it is not shipped.

Development only: @playwright/test and Playwright 1.64.1, Apache-2.0 (https://github.com/microsoft/playwright). Installed notices remain in node_modules. System Chrome for Testing used only for QA, not redistributed. Python stdlib build tool uses installed CPython (PSF). No public license granted for commissioned original application or supplied artwork.
