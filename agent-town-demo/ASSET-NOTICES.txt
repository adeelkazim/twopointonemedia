# Asset provenance and notices

The town is original pixel raster artwork drawn by src/art.js and src/architecture.js using Canvas2D integer rectangles. No external town tiles, game art, fonts, textures or 3D models are shipped. Inspired by the supplied plaza composition: open square, workshops, trees, bulletin, central guide. Industrial architecture includes a reactor hall, clock tower, observation tower, crystal spire, maker foundry, terminal hall, approval arch and distinct district pavilions, archives, terraces and sky docks. Teal/violet utility conduits and brass machinery are illustrative, not telemetry. The original reference image is preserved only under references/ and is not shipped.

Adeel portrait and front/back/side sprites are actual crops of the user-supplied character sheet. Beige background is removed using an edge-connected flood mask; no face or body is regenerated. Bounds and pixel counts: evidence/crops.json. Original sheet preserved only in references/. User-supplied artwork ownership is not inferred or relicensed; the reviewer must confirm publication rights before publishing these crops.

Public stable identity metadata and the data.js validator/store, adapter.js dormant transport, demo.js synthetic fixture are selectively reused from the accepted local Agent Town client 0.1.0. AK project source, no public source license inferred. adapter.js is source-only and is not shipped in either static build. No backend is rebuilt, changed or deployed.

Runtime dependencies: none. Native browser Canvas2D, HTML/CSS and system Georgia/Trebuchet/monospace font fallbacks. No external font network requests.

Development only: @playwright/test and Playwright 1.64.1, Apache-2.0 (https://github.com/microsoft/playwright). Installed notices remain in node_modules. System Chrome for Testing used only for QA, not redistributed. Python stdlib build tool uses installed CPython (PSF). No public license granted for commissioned original application or supplied artwork.
